# Notes for AI agents — The Gilded Order (thegildedorder.com)

Static site generator (`node build.js` → `dist/`) + Cloudflare Pages Functions (`functions/`). Deploys from `main` (Cloudflare Pages builds every push). No `cloudflare` branch.
Languages: English `/`, French `/fr/`, Brazilian Portuguese `/pt/`. Every product/article needs all three languages or the build stops.
Read README.md first.

## SEO (automated tasks run on this repo)
- Articles ("The Archive", /archive/<slug>/): base data in `data/content.js`, translations in `data/articles.i18n.js`. New article = add to both, in EN, FR and PT. Original writing about symbolism/history — no claims of real secret-society membership or affiliation with any real fraternity, no invented history presented as fact.
- Country landing pages: `data/countries.js` (Africa focus: South Africa, Kenya, Cameroon EN/FR, DR Congo, Mali, Chad, Côte d'Ivoire, Senegal).
- Shop: products in `data/products.js` (+ `data/products.i18n.js`). Prices marked `priceToConfirm` are estimates — never change prices.
- Sitemap and robots are generated by build.js. /cart/, /thank-you/ and 404 are noindex on purpose.
- Contact is WhatsApp +1 579 794 0146 only (no email on the site); membership is free. Don't change these.
- Log every SEO change in `seo/log.md`. IndexNow key `52447ccd075156206d1a9189cc54f7b6` (written by build.js).
- Check before pushing: `node build.js` must finish without errors.
